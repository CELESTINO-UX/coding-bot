Configure the AI backend and see the expected API format

A browser-only HTML page cannot understand every possible prompt by itself. Run a backend that calls your chosen AI provider, keep provider credentials on that server, then enter its URL here. Do not put secret API keys in this page.

The page sends a POST request with JSON and expects JSON back in this shape:

Request: { "prompt": "user's written request" } Response: { "summary": "Short description", "steps": ["Step one", "Step two"], "code": "Generated code as text", "previewHtml": "Optional HTML for the sandboxed preview" }

For local development, set up a backend route at /api/prompt and keep the AI provider key in a server-side environment variable. The backend should validate requests, enforce limits, and return the response format above.
