A small local coding agent

Coding Bot

Coding Bot helps with coding tasks in a Python project through an OpenAI-compatible Chat Completions API.

  • Run coding tasks from the command line.
  • Use an optional local web interface.
  • Keep file access and allowed shell commands within your project root.

Requires Python 3.10+ and an API key in OPENAI_API_KEY. The web interface binds to localhost; this Pages site is documentation only and does not run the bot.
